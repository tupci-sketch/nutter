# Completion Ledger

Every feature ID in the platform is tracked here. A row is complete only when all ten dimensions are satisfied per Chapter 60.3: database, service, packet/route, UI, DCC, permission, test, metric, asset, documentation.

Status values: `pending` | `in-progress` | `complete` | `blocked`
